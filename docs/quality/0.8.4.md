# Quality report for 0.8.4.1

## Measurement conditions

The `readability-lxml==0.8.4.1` package, corresponding to git tag `0.8.4.1`,
was measured on Python 3.13 using 146 saved pages and the
[common methodology](methodology.md) with UTF-8 text input. This historical report
predates the 20-page Dragnet sample.

## Aggregate result

| Pages | Overlap | Extracted tokens | Ideal tokens | Precision | Recall | F1 |
|---:|---:|---:|---:|---:|---:|---:|
| 146 | 174 673 | 179 776 | 198 361 | 0.972 | 0.881 | 0.924 |

F1 is below the `0.95` regression threshold. Bytes input fails on all 146 pages
before extraction because the encoding detector applies string regular
expressions to bytes. The package cannot be installed normally on Python 3.14
because its lxml constraint selects a release without a compatible wheel.
