# Extraction quality

The quality documentation is organized by purpose:

- [benchmark methodology](methodology.md) defines the corpus, extraction
  protocol, tokenization, and metrics;
- [0.9 quality report](0.9.md) records the release benchmark and security
  checks;
- [0.8.4.1 baseline](0.8.4.md) preserves the previous-version benchmark;
- [engine comparison](comparison.md) summarizes the ten-engine comparison;
- [detailed extraction results](detailed-results.md) contains complete corpus,
  failure, diagnostic, and per-page tables;
- [user issue corpus](user-corpus.md) records the issue-derived fixtures.

Raw machine-readable comparison results are stored in `benchmarks/results/`.
Saved page fixtures and their provenance are stored under `pages/`.
