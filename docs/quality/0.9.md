# Quality report for 0.9

## Measurement conditions

The current 0.9 state was measured on 166 saved pages using the
[common methodology](methodology.md). The benchmark reads source HTML as bytes.

The corpus consists of 10 base, 20 Dragnet, 6 user, and 130 Mozilla fixtures.
The Dragnet sample contains the first 20 UUIDs from the upstream list at commit
`5d97da4c3c5cf775fa02794b84d31786b8d51d3a`; the data license is CC BY 4.0.

Tests additionally use 15 regression fixtures from `jcharum/lxml-readability`.
Their manually checked `ideal.html` files are excluded from this report's
metrics; separate results appear in the [engine comparison](comparison.md).

## Aggregate result

| Pages | Overlapping tokens | Extracted tokens | Ideal tokens | Precision | Recall | F1 |
|---:|---:|---:|---:|---:|---:|---:|
| 166 | 201 371 | 203 238 | 210 572 | 0.991 | 0.956 | 0.973 |

The version passes the F1 `0.95` regression threshold. Compared with 0.8.4.1,
precision changed by `+0.019`, recall by `+0.072`, and F1 by `+0.048`. Bytes
input was processed successfully on all 166 pages.

The lowest results are `mozilla/nytimes-5` (`0.059`),
`mozilla/hukumusume-greedy-dog` (`0.537`), and `mozilla/wikipedia-4` (`0.753`).
The ideal output for `hukumusume-greedy-dog` includes the site directory and
related widgets in addition to the story, so this result is not an extraction
defect.

## Output security checks

The token benchmark does not measure HTML security. Separate regression tests
verify the removal of scripts, event attributes, and `javascript:` URLs.
Retained video iframes are restricted to exact HTTP(S) YouTube and Vimeo
hostnames; lookalike hosts, URLs with userinfo, and active `srcdoc` are removed.
